# Security policy

## Supported versions

Until FlagWire reaches `1.0.0`, only the latest published SDK version receives security fixes.

## Reporting a vulnerability

Please use this repository's **Security** tab to submit a private vulnerability report. Do not
open a public issue for suspected vulnerabilities or include secrets, customer data, or working
exploits in public discussions.

Include the affected package and version, impact, reproduction steps, and any suggested
mitigation. We will acknowledge a complete report as soon as practical and coordinate disclosure
after a fix is available.

## Release integrity

Official npm releases are produced only by the protected GitHub Actions release workflow. npm
provenance links each package to its public source commit and build. Maintainers do not publish
release artifacts from local machines.
